##  Application Preview

**Anatomia** is a gamified mobile learning application designed for **Radiologic Technology students**. It combines interactive 3D anatomy, anatomy identification gameplay, quizzes, classrooms, gamification, progress tracking, notifications, and student profiles.

The preview below highlights the major student and Teacher interfaces.

#  Offline Support

Anatomia is primarily an online application with selected offline-supported functionality.

Previously authenticated students can access selected learning functionality while offline.

### Offline-Supported Features

- Previously authenticated student access
- Local Play Mode progress
- Local anatomy learning data
- Offline authentication
- Synchronization when connectivity is restored

Features requiring fresh cloud data, classroom information, quizzes, or Firebase communication require an internet connection.

---

#  Educational Purpose

Anatomia is intended to supplement anatomy instruction by providing students with an interactive environment for learning and practicing anatomical identification.

It does not replace formal classroom instruction, laboratory activities, textbooks, medical references, or professional healthcare education.
